# Mathematical Modelling Portfolio
This repository contains my personal projects in mathematical modelling, machine learning, quantitative finance, and scientific computing.
I am currently preparing to study Engineering Mathematics at the University of Bristol.

## Projects

### 01. Random Walk Simulation
Simulation and visualization of random walk processes in one and two dimensions.

### 02. Stock Price Analysis
Analysis of historical stock price data with financial metrics, statistical summaries, and visualizations including moving averages, returns distribution, cumulative returns, and drawdown analysis.

### 03. Multiple Stock Comparison
Comparison of AAPL, MSFT, GOOGL, and SPY using normalized prices, cumulative returns, return distributions, correlations, and annualized risk-return statistics.
